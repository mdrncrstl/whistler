# Masterdeck auth email hook

This function is the branded Supabase Auth Send Email Hook for Masterdeck. It handles signup confirmation, magic links, password recovery, invitations, email changes and reauthentication codes through Resend.

Deploy it with JWT verification disabled because the function verifies Supabase's `SEND_EMAIL_HOOK_SECRET` signature:

```sh
supabase functions deploy masterdeck-auth-email --no-verify-jwt
```

Set these Edge Function secrets before enabling the hook:

```sh
supabase secrets set \
  RESEND_API_KEY=re_... \
  AUTH_FROM_EMAIL='Masterdeck <hello@masterdeck.app>' \
  AUTH_REPLY_TO='support@masterdeck.app' \
  SEND_EMAIL_HOOK_SECRET='v1,whsec_...'
```

In Supabase Dashboard, open Authentication → Hooks → Send Email, choose HTTPS, use the deployed function URL, generate the signing secret, save it as `SEND_EMAIL_HOOK_SECRET`, and then enable the hook. Verify `masterdeck.app` in Resend before using `hello@masterdeck.app` as the sender.

The hook replaces Supabase's default auth mailer. The confirmation link is still generated by Supabase, so signup verification and expiry behavior remain unchanged.
